# Publicar nuvynieves.com

El dominio comprado en Porkbun es la dirección; hace falta alojar los archivos para
que la página esté disponible en internet. Este proyecto es un sitio estático, así
que puede alojarse en un servicio de páginas estáticas.

## Archivos que deben subirse

Publica el contenido de esta carpeta con estos archivos públicos:

- `index.html` (página pública)
- `assets/` (logo e icono)

Publica únicamente el contenido de `sitio-web/`. No subas el repositorio completo,
el sistema de caja, `cliente.html`, credenciales, datos de Firebase ni información
de operación. El punto de venta no está diseñado para servir como página pública.

## Conectar el dominio

1. Elige un proveedor de alojamiento estático y crea un sitio con estos archivos.
2. En ese proveedor, agrega `nuvynieves.com` como dominio personalizado.
3. El proveedor te mostrará los registros DNS específicos que debes usar. En
   Porkbun, abre **Domain Management → Details → DNS Records** y agrega exactamente
   los registros que indique el proveedor.
4. Configura también `www.nuvynieves.com` si el proveedor lo recomienda y elige
   cuál de las dos direcciones será la principal.
5. Espera a que se actualicen los DNS y a que el proveedor active HTTPS; después
   verifica `https://nuvynieves.com` y `https://www.nuvynieves.com`.

Los valores DNS dependen del servicio de alojamiento elegido, por eso no se incluyen
registros inventados aquí. Esta guía no cambia la configuración de Porkbun ni publica
el sitio.

## Antes de anunciar la página

- Completa la dirección exacta, teléfono/WhatsApp, redes sociales y horario si
  quieres mostrarlos. Por ahora solo se indica Villa Juárez para no inventar datos.
- Revisa que la lista de sabores y toppings coincida con lo que vendes hoy.
- Considera reemplazar la foto del letrero por fotos de producto cuando las tengas.
- Prueba la página en celular y verifica los enlaces después de publicarla.
